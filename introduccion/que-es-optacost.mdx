## Introducción

**Optacost** es una plataforma empresarial completa diseñada para la gestión integral de laboratorios médicos, análisis de costos de prácticas y optimización de suministros.

## Stack Tecnológico

Optacost está construido con tecnologías modernas y robustas:

- **Frontend**: Next.js 14 + React 18 + TypeScript
- **Backend**: Supabase (PostgreSQL)
- **UI**: Shadcn/ui + Tailwind CSS
- **Estado**: Recoil + TanStack React Query
- **IA**: OpenAI GPT-5 con Model Context Protocol (MCP)

## Arquitectura Multi-tenant

Optacost utiliza una arquitectura multi-tenant basada en subdominios:

```
https://{cliente}.app.optacost.com
```

Cada cliente tiene:
- **Schema de base de datos dedicado**
- **Datos completamente aislados**
- **Configuraciones personalizadas**
- **Roles y permisos independientes**

<Info>
Aprende más sobre la arquitectura multi-tenant en la [sección de arquitectura](/arquitectura/multi-tenancy).

## Roles de Usuario

Optacost soporta 4 niveles de acceso:

| Rol | Nivel | Permisos |
|-----|-------|----------|
| **SuperAdmin** | 9 | Control total de la plataforma |
| **Admin** | 1 | Gestión completa del cliente |
| **Editor** | 3 | Edición limitada de datos |
| **User** | 2 | Solo lectura |
