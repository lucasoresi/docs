# Navegación del Sistema

El dashboard de Optacost cuenta con una barra lateral (Sidebar) dividida en dos secciones principales: **Gestión** y **Configuración**. Esta estructura permite separar las tareas operativas diarias de las tareas administrativas.

## 1. Sección Gestión
Esta sección contiene las herramientas para el análisis de costos y operaciones diarias.

*   **Home (Resumen)**: Tu punto de partida. Muestra alertas críticas sobre costos desactualizados. Es la página por defecto al iniciar sesión.
*   **Derivaciones**: Gestión de prácticas que se envían a terceros. Aquí puedes controlar los costos y márgenes de los estudios tercerizados.
*   **Obras sociales**:
    *   **Análisis general**: Gráficos de evolución del valor UB y comparativas de rentabilidad entre obras sociales.
    *   **Aranceles**: Listados detallados de precios por práctica y obra social.
*   **Prácticas**: El catálogo maestro de estudios médicos que realiza el laboratorio, con sus costos asociados.
*   **Insumos**: Base de datos de materiales y reactivos, con precios de compra y proveedores.
*   **Costos extra**: Registro de gastos indirectos o fijos que afectan la rentabilidad global.
*   **Facturación**: Módulo para generar reportes de facturación y seguimiento financiero.

## 2. Sección Configuración
Herramientas administrativas para el control de la cuenta y el sistema.

*   **Usuarios del sistema**: Administración de roles y permisos para el equipo del laboratorio.
*   **Backups**: Gestión de copias de seguridad de la base de datos para garantizar la seguridad de la información.
*   **Integraciones**: Configuración de conexiones con sistemas externos (APIs, LIS, etc.).
*   **Clientes**: Gestión de las entidades o pacientes (si aplica a la configuración del laboratorio).

## Elementos Comunes
En todas las páginas encontrarás:
*   **Barra Superior**: Acceso al perfil de usuario y notificaciones.
*   **Selectores de Fecha**: Muchos gráficos permiten filtrar por rangos de tiempo personalizados.
