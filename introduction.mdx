## ¿Qué es Optacost?

Optacost es una **plataforma integral de gestión de costos** diseñada específicamente para laboratorios de análisis clínicos. Te permite controlar cada aspecto de tu operación: desde el inventario de suministros hasta la facturación por obra social, con análisis en tiempo real y asistencia con inteligencia artificial.

## API REST Completa

Integra Optacost con tus sistemas existentes usando nuestra API REST:

```bash
# Ejemplo: Obtener prácticas del mes
curl -X GET "https://api.optacost.com/v1/practices?month=2024-12" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
