---
title: 'Historial de Conversaciones'
api: 'GET /api/chat/history'
description: 'Obtiene el historial de conversaciones con el chatbot'
---

## Endpoint

```bash
GET /api/chat/history
```

## Query Parameters

<ParamField query="conversation_id" type="string">
  ID específico de conversación
</ParamField>

<ParamField query="limit" type="number" default="50">
  Cantidad de mensajes a recuperar
</ParamField>

<ParamField query="offset" type="number" default="0">
  Offset para paginación
</ParamField>

## Request Example

```bash
GET /api/chat/history?conversation_id=conv_789&limit=20
Authorization: Bearer <token>
```

## Eliminar Conversación

```bash
DELETE /api/chat/history/:conversation_id
Authorization: Bearer <token>
```

## Códigos de Respuesta

| Código | Descripción |
|--------|-------------|
| 200 | Historial recuperado |
| 401 | No autenticado |
| 404 | Conversación no encontrada |
| 500 | Error del servidor |
