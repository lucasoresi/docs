## Descripción General

El endpoint de chat permite interactuar con el asistente de IA que puede:
- Responder preguntas sobre tus datos
- Generar análisis en lenguaje natural
- Ejecutar consultas SQL automáticamente
- Proporcionar insights sobre tu operación

## Endpoint

```bash
POST /api/chat
```

## Body Parameters

<ParamField body="message" type="string" required>
  Mensaje o pregunta del usuario
</ParamField>

<ParamField body="conversation_id" type="string">
  ID de conversación para mantener contexto
</ParamField>

<ParamField body="context" type="object">
  Contexto adicional opcional

  <Expandable title="context">
    <ParamField body="lab_id" type="string">
      ID del laboratorio (automático del usuario)
    </ParamField>

    <ParamField body="current_page" type="string">
      Página actual del usuario para contexto
    </ParamField>
  </Expandable>
</ParamField>

## Request Example

```bash
POST /api/chat
Authorization: Bearer <token>
Content-Type: application/json

{
  "message": "¿Cuánto gastamos en suministros el mes pasado?",
  "conversation_id": "conv_789",
  "context": {
    "current_page": "dashboard"
  }
}
```

## Response

<ResponseField name="response" type="string">
  Respuesta del asistente en lenguaje natural
</ResponseField>

<ResponseField name="conversation_id" type="string">
  ID de la conversación (úsalo en próximos mensajes)
</ResponseField>

<ResponseField name="data" type="object">
  Datos estructurados si corresponde

  <Expandable title="data">
    <ResponseField name="sql_query" type="string">
      Query SQL ejecutada (si aplicable)
    </ResponseField>

    <ResponseField name="results" type="array">
      Resultados de la consulta
    </ResponseField>

    <ResponseField name="visualization" type="object">
      Datos para gráficos si corresponde
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="suggestions" type="array">
  Preguntas sugeridas para continuar
</ResponseField>

## Seguridad

<Note>
El chatbot solo puede acceder a datos del laboratorio del usuario autenticado (Row Level Security)
</Note>

## Límites

- Máximo 10 mensajes por minuto
- Mensajes de hasta 1000 caracteres
- Contexto de conversación limitado a últimos 10 mensajes

## Códigos de Respuesta

| Código | Descripción |
|--------|-------------|
| 200 | Respuesta exitosa |
| 400 | Mensaje inválido |
| 401 | No autenticado |
| 429 | Rate limit excedido |
| 500 | Error del servidor |
