---
title: 'Listar Suministros'
api: 'GET /api/supplies'
description: 'Obtiene el inventario completo de suministros con filtros'
---

## Endpoint

```bash
GET /api/supplies
```

## Query Parameters

<ParamField query="search" type="string">
  Buscar por nombre o código
</ParamField>

<ParamField query="categoria" type="string">
  Filtrar por categoría
</ParamField>

<ParamField query="stock_bajo" type="boolean">
  Solo suministros con stock bajo
</ParamField>

<ParamField query="limit" type="number" default="100">
  Cantidad máxima de resultados
</ParamField>

## Request Example

```bash
GET /api/supplies?stock_bajo=true&limit=20
Authorization: Bearer <token>
```
