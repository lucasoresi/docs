El módulo de **Reportes** te permite generar análisis completos de la operación de tu laboratorio, con métricas de costos, consumos y productividad.

## Reporte General

### Filtros Disponibles

Personaliza tus reportes con múltiples filtros:

```tsx
// Opciones de filtrado
{
  periodo: "mes_actual", // últimos_7_dias, mes_pasado, año_actual, personalizado
  obra_social: "OSDE",
  tipo_practica: "Hemograma",
  laboratorio: "Lab Central",
  profesional: "Dr. Juan Pérez"
}
```

### Métricas Incluidas

Cada reporte incluye:
- Cantidad de prácticas realizadas
- Costo total de suministros
- Precio facturado
- Margen de ganancia
- Tiempo promedio de procesamiento

## Comparativas

Compara resultados entre diferentes periodos:

```tsx
// Ejemplo de comparativa
{
  periodo_actual: {
    total_practicas: 450,
    costo_total: 12500,
    facturacion: 28000
  },
  periodo_anterior: {
    total_practicas: 420,
    costo_total: 11800,
    facturacion: 26500
  },
  variacion: {
    practicas: "+7.1%",
    costos: "+5.9%",
    facturacion: "+5.7%"
  }
}
```

<Tip>
Usa las comparativas mensuales para identificar tendencias y tomar decisiones informadas
</Tip>
