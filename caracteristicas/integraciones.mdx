## Supabase

### Características Integradas

Optacost utiliza Supabase como backend principal:

- **Base de datos PostgreSQL**: Almacenamiento seguro y escalable
- **Autenticación**: Sistema completo de usuarios y permisos
- **Storage**: Almacenamiento de archivos y documentos
- **Realtime**: Actualizaciones en tiempo real
- **Edge Functions**: Funciones serverless para tareas automatizadas

### Row Level Security (RLS)

<Note>
Todos los datos están protegidos con políticas de seguridad a nivel de fila, garantizando aislamiento entre laboratorios
</Note>

```sql
-- Ejemplo de política RLS
CREATE POLICY "Users can only see their lab's data"
ON practices
FOR SELECT
USING (lab_id = auth.uid());
```

### Configuración

Para activar el chatbot:

<Steps>
  <Step title="Obtén API Key">
    Crea una cuenta en OpenAI y genera una API key
  </Step>
  <Step title="Configura la Key">
    Agrega la key en las variables de entorno
    ```bash
    OPENAI_API_KEY=sk-...
    ```
  </Step>
  <Step title="Activa el Chatbot">
    El botón del chatbot aparecerá automáticamente
  </Step>
</Steps>

<Warning>
Las API keys de OpenAI tienen costo por uso. Monitorea tu consumo en el dashboard de OpenAI
</Warning>

## AppSheet (Legacy)

### Sincronización de Datos Antiguos

Si vienes de una implementación anterior con AppSheet:

- Importa datos históricos automáticamente
- Migra usuarios y configuraciones
- Mantén compatibilidad durante la transición

```javascript
// Ejemplo de sincronización
const syncFromAppSheet = async () => {
  const legacyData = await fetchAppSheetData();
  const practices = transformToNewFormat(legacyData);
  await supabase.from('practices').insert(practices);
}
```

## API REST de Optacost

### Integración Personalizada

Conecta tus propios sistemas usando nuestra API:

```bash
# Autenticación
POST /api/auth/login
Content-Type: application/json

{
  "email": "usuario@lab.com",
  "password": "***"
}
```

```bash
# Obtener prácticas
GET /api/practices?month=2024-12
Authorization: Bearer <token>
```
