## Gráficos y Visualizaciones

### Evolución de Costos

Gráfico de línea que muestra la evolución temporal de costos:

- **Período**: Últimos 12 meses por defecto
- **Filtros**: Por laboratorio, práctica o suministro
- **Comparativa**: Mes actual vs mes anterior

```typescript
// Ejemplo de datos del gráfico
{
  labels: ['Ene', 'Feb', 'Mar', 'Abr', 'May', 'Jun'],
  datasets: [{
    label: 'Costo Total',
    data: [45000, 52000, 48000, 51000, 55000, 53000]
  }]
}
```

## Widgets Personalizables

### Organización del Dashboard

El dashboard permite personalizar la disposición de widgets:

<Steps>
  <Step title="Activar modo edición">
    Click en el ícono de configuración (⚙️) → "Personalizar Dashboard"
  </Step>
  <Step title="Reorganizar widgets">
    Arrastra y suelta los widgets en la posición deseada
  </Step>
  <Step title="Mostrar/Ocultar">
    Marca o desmarca widgets según tus necesidades
  </Step>
  <Step title="Guardar configuración">
    Los cambios se guardan automáticamente por usuario
  </Step>
</Steps>

### Widgets Disponibles

- **Métricas Financieras**: Costos, ingresos, márgenes
- **Actividad Reciente**: Últimas acciones en el sistema
- **Alertas y Notificaciones**: Avisos importantes
- **Gráficos de Tendencias**: Evolución temporal de KPIs
- **Top Rankings**: Prácticas y suministros destacados
- **Estado de Integraciones**: Conexiones externas activas

## Exportación de Datos

### Exportar Dashboard

Puedes exportar los datos visualizados:

- **PDF**: Vista completa del dashboard con gráficos
- **Excel**: Datos tabulares para análisis
- **Imagen**: Capturas de gráficos individuales

```typescript
// Opciones de exportación
{
  formato: "pdf" | "excel" | "png",
  incluir: ["metricas", "graficos", "tablas"],
  periodo: { desde: "2024-01-01", hasta: "2024-12-31" }
}
```

## Actualizaciones en Tiempo Real

El dashboard se actualiza automáticamente:

- **Datos en vivo**: Refresh cada 30 segundos
- **Notificaciones**: Alertas instantáneas
- **Colaboración**: Cambios de otros usuarios en tiempo real

<Info>
Los datos se sincronizan automáticamente. No necesitas recargar la página.
</Info>
